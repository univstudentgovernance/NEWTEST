# 대학 학생자치 뉴스 모니터

하루 두 번 Google News 검색 RSS와 주요 언론사의 공식 RSS에서 **RSS가 제공하는 제목·요약·출처·링크·발행시각만** 수집하는 GitHub Pages용 정적 사이트입니다. 기사 본문 페이지를 요청하거나 파싱하지 않으므로 robots.txt를 우회하지 않으며 로그인, 페이월, CAPTCHA도 건드리지 않습니다.

현재 공식 RSS는 연합뉴스·SBS 뉴스·한겨레·경향신문·매일경제·한국경제·동아일보·JTBC 뉴스와 이대학보·대학신문·연세춘추·고대신문·채널PNU·서울시립대신문·충대신문·숭대시보·KNSU 미디어를 사용합니다. 공식 언론사 RSS에서 발견된 기사는 해당 언론사의 원문 URL을 저장합니다. Google News 검색 RSS로 발견된 기사도 수집 단계에서 원문 주소로 변환합니다. 이 사이트 자체에는 기사 목록만 표시하며 기사 본문은 제공하지 않습니다.

Google News 검색 RSS의 중계 링크는 수집 시 원 언론사 URL로 변환합니다. 변환할 수 없는 경우에는 무한 로딩되는 중계 링크를 저장하지 않고 기사 제목 검색 주소를 사용합니다. RSS에 썸네일이 제공되면 목록에 표시하며, 이미지가 없으면 분야별 대체 썸네일을 표시합니다.

예약 실행 시간이 지나치게 길어지지 않도록 Google 중계 링크의 원문 변환은 실행당 최대 8건씩 처리합니다. 아직 변환되지 않은 기존 기사는 제목 검색으로 정상 이동하며, 이후 예약 실행 때 순차적으로 원문 직접 링크로 교체됩니다.

Google News가 제목 뒤에 붙인 언론사명은 제거한 뒤 비교합니다. 정리된 기사 제목이 완전히 동일한 경우에는 여러 검색어 또는 RSS에서 발견되어도 한 건만 저장합니다. 문장이나 문장부호가 다른 기사는 별개 기사로 유지합니다.

대학언론 자체 RSS에서 수집한 기사는 기사 사진 대신 해당 대학 공식 도메인의 로고 아이콘을 썸네일로 사용합니다. 로고는 잘리지 않도록 흰 배경에 맞춤 표시합니다. 일반 언론과 Google News 기사는 RSS가 제공하는 기사 이미지를 계속 우선 사용합니다.

## 선정한 키워드

최근 총학생회 관련 보도를 표본 조사해 다음 기사군을 반영했습니다.

- 핵심어: 총학생회, 총학, 학생자치
- 선거·조직: 선거, 당선, 후보, 선본, 투표율, 비대위, 궐위
- 등록금·교육: 등록금, 등록금심의위원회, 등심위, 교육권
- 의결·자치: 학생총회, 전체학생대표자회의, 전학대회, 중운위
- 재정·감사: 학생회비, 자치비, 회계, 예산, 결산, 감사
- 복지·문화: 축제, 대동제, 복지, 공약, 시설
- 인권·갈등: 인권, 차별, 징계, 논란, 성명, 집회

초중고 학생회 결과를 줄이기 위해 대학 맥락을 필수로 검사하고 `전교학생회`, 초·중·고등학교 등의 표현은 제외합니다. 세부 검색어와 분류어는 `config.json`에서 수정할 수 있습니다.

## GitHub에 올리기

1. 이 폴더의 내용 전체를 저장소 기본 브랜치에 올립니다.
2. 저장소 **Settings → Actions → General → Workflow permissions**에서 `Read and write permissions`를 허용합니다.
3. **Actions → Collect student council news → Run workflow**를 한 번 실행합니다.
4. **Settings → Pages → Build and deployment**에서 `Deploy from a branch`, 기본 브랜치와 `/ (root)`를 선택합니다.

이후 한국시간 09:00, 21:00에 예약됩니다. GitHub 예약 작업은 혼잡도에 따라 실제 시작이 다소 늦어질 수 있습니다. Actions가 첫 실행 때 `data/news.json`을 갱신하고 자동 커밋합니다.

## 수집 윤리와 운영 원칙

- RSS 주소만 요청하고 개별 기사 페이지는 크롤링하지 않습니다.
- RSS에 실린 짧은 메타데이터만 저장하며 기사 전문·이미지는 복제하지 않습니다.
- 각 결과는 원 언론사로 이동하게 하고 새 창 링크에는 `noopener noreferrer`를 사용합니다.
- 각 RSS 요청 사이에 1.2초 간격을 둡니다.
- 동일 제목 기사는 여러 질의에 걸려도 한 번만 보존합니다.
- 공급자가 RSS 제공을 중단하거나 이용조건을 바꾸면 해당 소스를 제거해야 합니다.
- SBS RSS는 공식 안내상 개인의 비상업적 사용에 한정되므로 상업적으로 운영할 경우 SBS와 별도 협의하거나 `config.json`에서 SBS 소스를 제거해야 합니다.

## 로컬 확인

```bash
python collector.py
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. 외부 패키지는 필요하지 않습니다.
